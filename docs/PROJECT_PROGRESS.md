# Selected Project Progress

Project progress in the public README is maintained in `data/profile.json`.
Private repository links, local paths, unreleased source and private hardware
evidence are not published.

Percentages use a deliberately conservative calculation:

```text
fully completed top-level roadmap stages / all top-level roadmap stages
```

Partial, substantially complete, started, planned and validation-pending stages
do not count as complete. This avoids assigning subjective fractional weights.

## HackPod — 33%

The HackPod roadmap has six top-level stages: Milestones 0, 1, 2 and 3,
Phase 4, and Milestone 4. Milestones 0 and 3 are fully complete. Milestone 1
retains an implementation caveat, Milestone 2 and product polish remain
partial, and Bluetooth audio transport remains in development.

Calculation: `2 / 6`, rounded to the nearest whole percentage.

## X-Link — 21%

The X-Link roadmap has fourteen numbered milestones, 0 through 13. Milestones
0, 1 and 2 are marked complete. Milestones described as substantially complete,
partially complete, implemented with hardware validation outstanding, or
framework-complete with direct installation still pending are excluded.

Calculation: `3 / 14`, rounded to the nearest whole percentage.

These percentages describe roadmap completion only. They do not reduce or
inflate the separately documented implemented and hardware-validated features.
